# Sphere-Mind (NEXUS)

A 3D multimedia knowledge graph application that visualizes ideas in a spherical, expandable form with database persistence.

## Features
- 3D visualization of ideas using React Three Fiber
- PostgreSQL database for persistent storage
- Hierarchical node structure with parent-child relationships
- Support for text, video, and audio nodes
- Drag-and-drop positioning in 3D space
- Futuristic cosmic design aesthetic

## Tech Stack
- Frontend: React, Three.js, TailwindCSS
- Backend: Express, Drizzle ORM
- Database: PostgreSQL (Neon)
